# 스팀 리뷰 분석기

스팀 유저 리뷰를 AI로 주제·감정·심각도별로 분류하고, 개발팀이 바로 쓸 수 있는 이슈 리포트로 정리하는 웹 앱.

> 스크린샷/GIF: (여기에 추가)

## 해결하려는 문제

라이브 서비스 중인 게임은 하루에도 수십~수백 개의 리뷰가 쌓인다. 운영·QA 담당자가 이걸 직접 읽고 "어떤 불만이 얼마나 많은지, 무엇부터 고쳐야 하는지" 정리하려면 몇 시간이 걸린다.
이 앱은 게임 주소 하나만 넣으면 그 과정을 1~2분 안에 끝낸다.

## 주요 기능

- 게임 이름 검색(자동완성), 스팀 상점 주소, 앱 ID 중 무엇으로든 게임 선택
- 최신 리뷰 최대 200개 수집 (한국어 / 영어 / 전체)
- 리뷰마다 AI가 주제(11종), 감정, 문제 심각도, 한 줄 요약을 매김
- 주제별 긍정·부정을 한눈에 보는 발산형 차트
- 비슷한 불만을 묶어 우선순위 이슈 Top 5와 근거 리뷰 연결
- 유저가 좋아하는 점, 다음 패치 제안 체크리스트
- 이슈 클릭 시 근거 리뷰만 필터링, 주제·감정·심각도 필터
- Jira·노션·깃허브 이슈에 바로 붙여넣는 Markdown 리포트 내보내기
- 예시 결과 바로 보기: 미리 분석해 둔 결과를 AI 호출 없이 즉시 표시 (대기 시간 0, 무료 사용량 절약)

## 설계 포인트

**2단계 AI 파이프라인**
1. 분류: 리뷰를 50개씩 나눠 개별 분류 (원문 사용)
2. 요약: 분류 결과(요약문)만 모아서 이슈 도출 → 원문을 다시 보내지 않아 토큰 사용량이 적음

**AI 출력의 신뢰성 확보**
- Gemini의 `responseSchema`로 JSON 구조와 enum 값을 강제
- 서버에서 한 번 더 검증: 모르는 id·카테고리는 버리고, 누락된 리뷰는 기본값으로 채워 화면에 표시
- 통계 숫자(추천 비율, 주제별 언급 수)는 AI가 아니라 코드로 계산 → 계산 실수 없음
- 이슈의 근거 리뷰 id는 실제 존재하는 것만 남김

**무료 인프라에서 안정적으로 동작**
- 클라이언트가 배치 단위로 API를 호출 → 요청 하나가 짧게 끝나 서버리스 시간 제한에 걸리지 않고, 진행률도 표시 가능
- 모델 자동 전환: 기본 모델이 붐비거나(503) 무료 한도에 걸리면(429) 다음 모델로 자동으로 넘어감 (`GEMINI_MODEL`에 쉼표로 순서 지정)
- 응답 없이 멈춘 요청은 40초 뒤 끊고 다음 모델로 전환
- 공개 배포 시 API 한도를 지키기 위해 요청당 리뷰 수 상한(200개)

**확장 가능한 구조**
- `lib/llm.ts`: "프롬프트 + JSON 스키마 → 결과"만 담당하는 공통 모듈. 모델이나 AI 공급자를 바꿀 때 이 파일만 수정
- `lib/review-analysis.ts`: 스팀 리뷰 기능 전용 프롬프트·스키마·검증
- 같은 구조로 유튜브 댓글 분석, 회의록 → 할 일 정리 기능을 추가할 예정

## 기술 스택

- Next.js 15 (App Router) + TypeScript
- Google Gemini API (무료 티어)
- Steam 공개 리뷰 API (키 불필요)
- 외부 UI 라이브러리 없이 CSS로 차트 구현, 다크 모드·모바일 대응
- Vercel 배포

## 폴더 구조

```
app/
  page.tsx                  메인 화면 (분석 흐름, 진행률)
  components/               입력 폼, 차트, 이슈 목록, 리뷰 목록
  api/search/               게임 이름 검색 (자동완성)
  api/steam/                스팀 리뷰 수집
  api/analyze/classify/     리뷰 분류 (50개 단위)
  api/analyze/summary/      이슈 도출·요약
lib/
  llm.ts                    공통 AI 호출 (재시도, JSON 파싱)
  steam.ts                  스팀 API, 앱 ID 파싱, 텍스트 정리
  review-analysis.ts        프롬프트, 응답 스키마, 응답 검증
  aggregate.ts              통계 계산
  markdown.ts               리포트 내보내기
```

## 로컬 실행

1. [Google AI Studio](https://aistudio.google.com)에서 무료 API 키 발급
2. 설치 및 실행
   ```bash
   npm install
   cp .env.example .env.local   # 윈도우: copy .env.example .env.local
   # .env.local 파일에 GEMINI_API_KEY 입력
   npm run dev
   ```
3. http://localhost:3000 접속

## 배포 (Vercel, 무료)

1. 이 폴더를 깃허브 저장소에 올림 (`.env.local`은 `.gitignore`에 있어 올라가지 않음)
2. [vercel.com](https://vercel.com)에서 깃허브 로그인 → Add New Project → 저장소 선택
3. Environment Variables에 `GEMINI_API_KEY` 추가 → Deploy

## 예시 결과 바꾸기

1. 앱에서 게임을 분석한 뒤 "결과 저장 (.json)" 클릭
2. 받은 파일 이름을 `sample-result.json`으로 바꿔 `public` 폴더에 넣기
3. 커밋·푸시하면 첫 화면에 "예시 결과 보기" 버튼이 생김
